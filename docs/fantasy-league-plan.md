# সাপ্তাহিক ফ্যান্টাসি লিগ: পরিকল্পনা

অবস্থা: **অপেক্ষায়**। প্লে স্টোরে প্রকাশের কাজ শেষ হলে শুরু হবে (প্রতিষ্ঠাতার সিদ্ধান্ত, নভেম্বর ২০২৬)।
সম্ভাব্য চালু: জানুয়ারির ট্রান্সফার উইন্ডোর পর, মৌসুমের দ্বিতীয়ার্ধে।

## প্রতিযোগিতা
- শুরুতে শুধু প্রিমিয়ার লিগ। প্রতি রাউন্ড (matchday) = এক সপ্তাহ।

## দল
- ১১ জন: ১ গোলরক্ষক, ৪ ডিফেন্ডার, ৪ মিডফিল্ডার, ২ ফরোয়ার্ড।
- এক ক্লাব থেকে সর্বোচ্চ ২ জন।
- বাজেটের বদলে তিন শ্রেণি: তারকা / ভালো / সাধারণ (মৌসুমের রেটিং আর গোল ধরে)। তারকা সর্বোচ্চ ৩ জন।
- অধিনায়ক: পয়েন্ট দ্বিগুণ। সহ-অধিনায়ক: অধিনায়ক না খেললে দ্বিগুণ।

## বদল
- প্রতি সপ্তাহে ২টা বিনা খরচে, এর বেশি প্রতিটা −৪।
- সপ্তাহের প্রথম খেলা শুরু হলে দল লক।

## পয়েন্ট
| কী হলে | পয়েন্ট |
|---|---|
| খেলেছেন: ৬০ মিনিটের কম / বেশি | ১ / ২ |
| গোল: ফরোয়ার্ড / মিডফিল্ডার / ডিফেন্ডার ও গোলরক্ষক | ৪ / ৫ / ৬ |
| অ্যাসিস্ট | ৩ |
| ক্লিন শিট (৬০+ মিনিট): গোলরক্ষক ও ডিফেন্ডার / মিডফিল্ডার | ৪ / ১ |
| হলুদ / লাল কার্ড | −১ / −৩ |
| ম্যাচের সেরা তিন রেটিং | +৩ / +২ / +১ |

## লিডারবোর্ড
- সাপ্তাহিক আর মৌসুম। বন্ধুদের লিগ (প্রেডিকশনের লিগের মতো)। সপ্তাহের সেরার ব্যাজ, শেয়ার কার্ড।

## ডেটা (যা আছে আর যা লাগবে)
- আছে: `match_live.players` = খেলোয়াড় আইডি ধরে `{ g, as, yc, rc, min, r, cap }` (গোল, অ্যাসিস্ট, কার্ড, মিনিট, রেটিং)।
  পজিশন `match_live.lineups` (xi/sub-এর `pos`: G/D/M/F)। ক্লিন শিট খেলার স্কোর থেকে।
- লাগবে: প্রিমিয়ার লিগের ২০ দলের স্কোয়াড, পজিশনসহ (API-Football `/players/squads`, দিনে একবার, ২০টা কল)।
- নতুন টেবিল: fantasy_players (শ্রেণিসহ), fantasy_teams, fantasy_picks (সপ্তাহ ধরে), fantasy_points।
- পয়েন্ট হিসাব: `api/live.js`-এর লাইভ আপডেটের সাথে, যাতে খেলা চলাকালেই পয়েন্ট বাড়ে।

## আনুমানিক কাজ
২–৩ সপ্তাহ: স্কোয়াড সিঙ্ক, দল বাছাইয়ের পাতা (মাঠের ছবিতে), পয়েন্ট হিসাব, লিডারবোর্ড আর বন্ধুদের লিগ, SQL।
